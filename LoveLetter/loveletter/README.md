# Love Letter

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=black)

A small React app made as a gift. Enter the secret code to open an animated love letter, then browse a photo gallery, little notes and favorite songs.

## Pages

- **Home:** secret-code entry
- **Love Letter:** animated letter
- **Gallery, Notes, Songs:** sections reached from the main page

## Run locally

```bash
npm install
npm start
```

Built with React 19 (Create React App) and React Icons.
